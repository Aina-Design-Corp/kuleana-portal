Green Fee Project Report — direct entry

For department points of contact and project leads. No Survey123 license, account, or app required — this page writes to the same hosted feature layer as Form 1, through the ArcGIS REST API, and lands in the same intake pipeline and publication gate.

Demonstration only: every project in this form is a fictional sample — no real award, awardee, or organization is represented, and no government adoption, endorsement, partnership, or deployment is claimed. Entries go nowhere: the page validates them and shows the REST calls it would make.
Demonstration mode No feature service is configured, so submitting shows the exact REST calls this page would make. Set CONFIG.featureServiceUrl to the hosted feature layer and the same entry submits live.
